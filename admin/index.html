Изменения сохраняются прямо в репозиторий GitHub, сайт обновляется сам примерно через минуту.

Где взять токен?
  1. Откройте github.com → Settings → Fine-grained tokens.
  2. Repository access → Only select repositories → выберите репозиторий сайта.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Создайте токен и вставьте сюда. Он хранится только в этом браузере.
